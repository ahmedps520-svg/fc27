FBX → GLB

Mixamo hands you the whole character inside every animation download, so ten animations means ten copies of the same mannequin. Drop them all here and this writes one .glb: the mesh and skeleton once, every animation as a named clip. Nothing is uploaded — it runs in this page. Name each file after the move (Mixamo's own filenames are fine); that name becomes the clip name the game asks for.

Exactly one download needs to be taken with skin — that is where the body comes from, and it can be any of them. The rest can be "without skin" at a tenth of the size. A .glb this tool made earlier can go back in alongside, so adding a character to a set of animations you already converted costs nothing.
